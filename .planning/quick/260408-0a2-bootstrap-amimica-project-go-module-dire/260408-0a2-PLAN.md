   - `func Load(path string) (*Config, error)` — loads YAML file, merges over defaults.

     - min_statements >= 1
     - min_lines >= 1

     - weight values in [0.0, 1.0]
     - max_file_size > 0
     - jobs >= 0
     - include patterns non-empty
     - normalization_level is valid string
     - output format is valid string
   - Return first error found (or collect all, preferable).

   - Level: parse "debug"/"info"/"warn"/"error" string to slog.Level. Default to info on invalid.
   - Format: "json" uses slog.NewJSONHandler(os.Stderr), "text" uses slog.NewTextHandler(os.Stderr). Default text.
   - Thin wrapper, no custom logger types. Return stdlib slog.Logger.
