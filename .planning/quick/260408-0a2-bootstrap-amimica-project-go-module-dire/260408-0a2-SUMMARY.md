# Quick Task 260408-0a2: Bootstrap Amimica Project (Go module + directory skeleton)

**One-liner:** Go module initialized with all 17 internal packages, core model types, slog logging wrapper, YAML config with env overrides and validation, and path-sandboxing fsguard — all compiling and tested.

## What Was Built

### Task 1: Go Module, Model Types, main.go, Makefile

Initialized `github.com/user/amimica` Go module and created the full directory skeleton (17 internal packages). Defined all core model types in `internal/model/`:

| Type | File | Purpose |
|------|------|---------|
| `SourceFile`, `SourceRegion`, `ParseError` | source.go | File-level and region metadata |
| `NormalizedUnit`, `UnitKind`, `UnitID` | unit.go | Analysis unit (function/block/window/subtree) |
| `Token`, `NormToken`, `NormalizationLevel` | token.go | Token representation before/after normalization |
| `Finding`, `CloneType` | finding.go | Clone detection result |
| `Score`, `Penalty` | score.go | Multi-dimensional quality scoring |
| `Evidence`, `RegionDiff`, `DiffHunk` | evidence.go | Justification for a finding |
| `RefactorHint`, `RefactorCategory` | refactor.go | Actionable refactoring suggestions |
| `FindingID` | findingid.go | Deterministic [20]byte ID with hex String() |

All iota types have `String()` methods: `UnitKind`, `NormalizationLevel`, `CloneType`, `RefactorCategory`.

`cmd/amimica/main.go` implements `version` subcommand with ldflags-injectable version string using the `flag` package.

`internal/logging/logging.go` provides `Setup(level, format string) *slog.Logger` — a thin slog wrapper.

### Task 2: Config, Logging, and fsguard Packages (TDD)

**TDD process followed:** Tests written first (RED), then implementation (GREEN).

**Config package** (`internal/config/`):
- `config.go`: Nested `Config` struct matching Section 9 schema exactly (Analysis, Scoring, Paths, Cache, Output, Performance, Logging sub-structs with yaml tags)
- `load.go`: `Load(path)` searches `.amimica.yaml` and `~/.config/amimica/config.yaml`, returns `Default()` on missing file; `ApplyEnv()` handles `AMIMICA_*` env vars
- `validate.go`: `Validate()` collects all errors — checks min_statements >= 1, min_lines >= 1, min_score in [0,1], weight values in [0,1], max_file_size > 0, include patterns non-empty, normalization_level valid, output format valid

**Logging package** (`internal/logging/`):
- `logging.go`: `Setup(level, format)` creates JSON or text handler on stderr with parsed level; invalid levels default to info

**fsguard package** (`internal/fsguard/`):
- `guard.go`: `New()` resolves roots to absolute paths and verifies they exist; `ValidatePath()` uses `filepath.Abs` + `filepath.Clean` + prefix check against all roots; `ValidateSymlink()` checks `os.Lstat` mode bits and enforces followSymlinks policy; `ValidateFileSize()` compares against maxSize
